# IPA sound recordings

Recordings of the English single vowels by real people, from Wikimedia Commons, trimmed and loudness-normalised by
`scripts/make-ipa-audio.py`. File names are the IPA symbol's code points (e.g. `28c.mp3` is /ʌ/).
Each file's source page, author and licence (CC BY-SA 3.0) are listed in `src/pron-audio.js` and shown
in the app (Giới thiệu → Nguồn các bản ghi âm phát âm). These edited versions are shared under the same licence.
