# Ín-Gờ-Lịt Mỗi Ngày – bản web

Học tiếng Anh từ con số 0 đến C1: lộ trình 6 chặng, 3.000 từ, 128 bài ngữ pháp, bài đọc có giọng đọc mẫu.
Miễn phí, không quảng cáo, không cần tài khoản, không thu thập dữ liệu. Học để tích phước.

Repo này chỉ chứa bản web đã dựng sẵn để phát hành (GitHub Pages). App Android:
